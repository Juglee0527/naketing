# Naketing Frontend

`naketing.co.kr`용 기존 Next.js App Router 앱입니다.

## 실행

```bash
npm install
npm run dev
```

기본 주소는 `http://localhost:3000`입니다.

## 검증

```bash
npm run lint
npm run build
```

## 현재 버전

정확한 버전과 스크립트는 `package.json`을 기준으로 합니다.

- Next.js 16.0.3
- React 19.2.0
- TypeScript 5
- Tailwind CSS 4

개발자 사이트와 전체 저장소의 배포 구조는 루트 `README.md`를 참고하세요.
